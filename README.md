# Mutfak Defterim

Yurt dışında kendi yemeğini yapanlar için tek dosyalık tarif defteri.

- **Tarifler:** 15 kolay Türk ev yemeği hazır gelir. Kendi tariflerini ekleyip düzenleyebilirsin. Porsiyon sayısını değiştirince malzemeler buna göre hesaplanır.
- **Alışveriş listesi:** Tarifin malzemelerini tek dokunuşla listeye eklersin, aynı malzemeler birleşir. Malzemelerin İngilizce ve Almanca market adlarını da gösterir.
- **Elimde ne var?:** Evdeki malzemeleri seçersin, en az eksikle yapabileceğin tarifler listelenir.
- **Yedek:** Veriler tarayıcıda saklanır. "Yedek" ile kopyasını alıp başka cihaza taşıyabilirsin.

Kullanmak için `index.html` dosyasını tarayıcıda açman yeterli. GitHub Pages açıksa telefondan da kullanılabilir.
